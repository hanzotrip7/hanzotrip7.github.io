Getting Started

Up and running in 30 seconds

Python 3.8 or later. No external package is required for core functionality. One optional install unlocks network chokepoint analysis.

bash
# Optional — enables the chokepoints command $ pip install networkx # Verify the install — runs against a built-in sample graph $ python3 whippet.py --cmd info ╔══════════════════════════════════════════════════════════════════╗ ║ 🩸 whippet v10.0.0 — BloodHound Attack Path Synthesizer ║ ║ Author: hanzotrip7 ║ ╚══════════════════════════════════════════════════════════════════╝ ℹ Demo mode — enterprise graph loaded ✓ Graph ready — 13 nodes, 14 edges

If you see the banner and a node count, you're ready. Now point it at your collection files. whippet auto-detects the format — SharpHound v5/v6, BloodHound CE exports, and AzureHound all work without any flags or extra configuration.

bash — loading your collection
# SharpHound — point at the whole directory $ python3 whippet.py -d /loot/collections/*.json --cmd info ℹ Detected collection files — merging… ✓ 20231103_computers.json → 412 Computer node(s) ✓ 20231103_users.json → 2,841 User node(s) ✓ 20231103_groups.json → 318 Group node(s) ✓ 20231103_domains.json → 2 Domain node(s) ✓ 20231103_gpos.json → 47 GPO node(s) ✓ 20231103_certtemplates.json → 22 CertTemplate node(s) ✓ Merged 3,642 nodes, 21,847 edges from 6 file(s)
Common gotcha: Always include your *_domains.json file in the glob. Domain nodes anchor Tier-0 detection. Without them, proximity scoring and several analysis commands return zero results.
Command Reference

17 commands. Every angle covered.

Every command prints directly to the terminal. Add --format json --out file.json to any of them for structured output you can feed into other tooling.

info
Graph summary and primitive counts. Run this first on every engagement to validate your data.
bulk
Every enabled user with a path to Tier-0, sorted by hop count for fast target prioritization.
kerberoast
SPN-bearing accounts ranked by Tier-0 proximity so you know which hashes are worth the effort.
asreproast
Accounts with pre-auth disabled. No initial credentials required to request the crackable material.
dcsync
Direct and transitive replication rights up to six hops deep, with full privilege chains.
laps
LAPS readers and the machines they can reach, including systems that path into Tier-0.
acl
ACL abuse paths to Tier-0 across multiple relationship types and write-control primitives.
delegation
Unconstrained, constrained, and RBCD delegation chains with practical exploitation notes.
adcs
Certificate template abuse classified by ESC type from ESC1 through ESC9.
azure
Azure / Entra attack paths across cloud privilege relationships and directory role escalation.
paths
Top-K ranked attack paths between arbitrary nodes, including per-hop abuse hints.
simulate
Narrative walk-through of the best route with noise awareness and suggested tradeoffs.
owned
Tier-0 reachability from a single compromised node with full hop breakdown.
blast
Blast radius from an owned node — reachable users, computers, sessions, and privileged paths.
chokepoints
Betweenness centrality ranking to identify the accounts whose hardening removes the most paths.
matrix
Reachability matrix showing every user versus every Tier-0 node with hop counts.
htmlreport
Self-contained interactive HTML report ready for handoff, offline review, or client deliverables.
Engagement Workflows

From no creds to Domain Admin

The commands are meant to chain together. Each phase uses the output of the previous one to narrow focus and reduce wasted effort.

  1. 01
    Orient the attack surface

    Run info first. Verify Tier-0 node count and primitive counts before you do anything else.

  2. 02
    Build the target list

    Use bulk for broad reachability and kerberoast to prioritize crackable accounts that actually matter.

  3. 03
    Assess a compromise

    owned tells you if the account leads to Tier-0. blast tells you how much damage it can do.

  4. 04
    Plan the route

    paths ranks viable attack chains. simulate converts the best one into a practical execution narrative.

  5. 05
    Generate the deliverable

    htmlreport gives you a self-contained artifact, while JSON output feeds slides, automation, or downstream tooling.

Operational Security

Route around what’s off-limits

OPSEC flags filter the graph at the edge level. Any route that depends on a blocked technique is removed before pathfinding returns results.

Flag What it blocks Use when
--stealthAll edges with high detection risk such as LSASS, DCSync, DCOMMDI / strong telemetry is in place
--no-lsassSession-based credential accessEDR blocks or heavily monitors LSASS
--no-dcsyncReplication abuse pathsRules of engagement prohibit replication attacks
--no-rdpInteractive RDP movementInteractive login is out of scope
--no-aclACL abuse primitivesWrite-control attacks are restricted
--no-execAdminTo, PSRemoting, DCOM, SQL adminExecution is restricted by the engagement
--no-delegationDelegation abuse chainsDelegation techniques are explicitly out of scope
--no-adcsAll ADCS certificate pathsPKI infrastructure is excluded
bash — constrained pathfinding
$ python3 whippet.py -d *.json --cmd paths \ --from "john.doe@CORP.LOCAL" \ --to "Domain Admins@CORP.LOCAL" \ --stealth --no-lsass --no-dcsync --top 3 Constraints: no_lsass, no_dcsync | Stealth: True Path #1 score=4.5 hops=3 noise=9 john.doe → helpdesk-admins → IT Admins → Domain Admins
