Getting Started

Up and running in 30 seconds

Python 3.8 or later. No external package is required for core functionality. One optional install unlocks network chokepoint analysis.

bash
# Optional — enables the chokepoints command $ pip install networkx # Verify the install — runs against a built-in sample graph $ python3 whippet.py --cmd info ╔════════════════════════════════════════════════════════╗ 🩸 whippet — BloodHound Attack Path Synthesizer Author: hanzotrip7 ╚════════════════════════════════════════════════════════╝ ℹ Demo mode — enterprise graph loaded ✓ Graph ready — 13 nodes, 14 edges

If you see the banner and a node count, you're ready. Now point it at your collection files. whippet auto-detects the format — SharpHound, BloodHound CE exports and AzureHound all work without any flags or extra configuration. * see readme for more details: https://github.com/hanzotrip7/whippet/blob/main/README.md

Common gotcha: Always include your *_domains.json file in the glob. Domain nodes anchor Tier-0 detection. Without them, several analysis commands return zero results.
Command Reference

17 commands.

Every command prints directly to the terminal. Add --format json --out file.json to any of them for structured output you can feed into downstream tooling.

info
Graph summary and primitive counts. Run this first on every engagement.
bulk
Enabled users with paths to Tier-0, sorted by hop count.
kerberoast
SPN-bearing accounts ranked by proximity to high-value targets.
asreproast
Accounts with pre-auth disabled and no initial credential requirement.
dcsync
Direct and transitive replication rights with full privilege chains.
laps
LAPS readers and the machines they can reach.
acl
ACL abuse paths across write-control and delegation primitives.
delegation
Unconstrained, constrained and RBCD abuse chains.
adcs
Certificate template abuse classified by ESC type.
azure
Azure / Entra privilege paths and cloud-side escalation.
paths
Top-K ranked attack paths between arbitrary nodes.
simulate
Narrative walk-through of the best route.
owned
Tier-0 reachability from a single compromised node.
blast
Blast radius from an owned node.
chokepoints
Betweenness centrality ranking for defensive hardening decisions.
matrix
User-to-Tier-0 reachability matrix with hop counts.
htmlreport
Single-file HTML report for handoff and offline review.
Engagement Workflows

From no creds to Domain Admin

The commands are designed to chain together. Each phase narrows focus and reduces wasted effort during assessment.

  1. 01
    Orient the attack surface

    Run info first. Verify Tier-0 node count and primitive counts before doing anything else.

  2. 02
    Build the target list

    Use bulk for broad reachability and kerberoast to prioritize crackable accounts that matter.

  3. 03
    Assess a compromise

    owned tells you if the account leads to Tier-0. blast tells you how much damage it can do.

  4. 04
    Plan the route

    paths ranks viable chains. simulate converts the best one into an execution narrative.

  5. 05
    Generate the deliverable

    htmlreport gives you a self-contained artifact, while JSON output supports automation and reporting.

Operational Security

Route around what’s off-limits

OPSEC flags filter the graph at the edge level. Any route that depends on a blocked technique is removed before pathfinding returns results.

Flag What it blocks Use when
--stealthHigh-noise edges such as LSASS, DCSync, DCOMStrong telemetry is in place
--no-lsassSession-based credential accessEDR blocks or heavily monitors LSASS
--no-dcsyncReplication abuse pathsReplication is prohibited by ROE
--no-rdpInteractive RDP movementInteractive sessions are out of scope
--no-aclACL abuse primitivesWrite-control attacks are restricted
--no-execAdminTo, PSRemoting, DCOM, SQL adminExecution is restricted
--no-delegationDelegation abuse chainsDelegation techniques are excluded
--no-adcsAll ADCS certificate pathsPKI infrastructure is out of scope
