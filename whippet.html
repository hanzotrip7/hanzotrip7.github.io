Getting Started

Up and running
in 30 seconds

Python 3.8 or later. No pip packages required for core functionality. One optional install unlocks network chokepoint analysis.

bash
# Optional — enables the chokepoints command $ pip install networkx # Verify the install — runs against a built-in sample graph $ python3 whippet.py --cmd info ╔══════════════════════════════════════════════════════════════════╗ ║ 🩸 whippet v10.0.0 — BloodHound Attack Path Synthesizer ║ ║ Author: hanzotrip7 ║ ╚══════════════════════════════════════════════════════════════════╝ ℹ Demo mode — enterprise graph loaded ✓ Graph ready — 13 nodes, 14 edges

If you see the banner and a node count, you're ready. Now point it at your collection files. whippet auto-detects the format — SharpHound v5/v6, BloodHound CE exports, and AzureHound all work without any flags or configuration.

bash — loading your collection
# SharpHound — point at the whole directory $ python3 whippet.py -d /loot/collections/*.json --cmd info ℹ Detected collection files — merging... ✓ 20231103_computers.json → 412 Computer node(s) ✓ 20231103_users.json → 2,841 User node(s) ✓ 20231103_groups.json → 318 Group node(s) ✓ 20231103_domains.json → 2 Domain node(s) ✓ 20231103_gpos.json → 47 GPO node(s) ✓ 20231103_certtemplates.json → 22 CertTemplate node(s) ✓ Merged 3,642 nodes, 21,847 edges from 6 file(s) # Combined AD + Azure in one unified graph $ python3 whippet.py -d /loot/sharphound/*.json /loot/azurehound.json --cmd info ✓ AzureHound: 891 nodes, 4,203 edges from azurehound.json ✓ Merged 4,533 nodes, 26,050 edges from 7 file(s)
Common gotcha: Always include your *_domains.json file in the glob. Domain nodes anchor the Tier-0 detection system. Without them, proximity scoring and most analysis commands return zero results.
Command Reference

17 commands.
Every angle covered.

Every command outputs directly to the terminal. Add --format json --out file.json to any of them for structured output you can pipe elsewhere.

info
Graph summary and all primitive counts. Run this first on every engagement to confirm data loaded correctly.
bulk
Every enabled user with a path to Tier-0, sorted by hop count. Your fastest prioritized target list.
kerberoast
SPN-bearing accounts sorted by hops to T0. Focus on accounts at 1–2 hops — ignore ∞.
asreproast
Pre-auth disabled accounts. No credentials required to request the hash.
dcsync
Direct and transitive DCSync rights. Transitive paths up to 6 hops deep, full chain shown.
laps
LAPS readers and which machines they control. Flags readers whose machines reach T0.
acl
All ACL abuse paths to Tier-0 across 13 relationship types.
delegation
Unconstrained, constrained, and RBCD delegation chains with exploitation notes.
adcs
Certificate template abuse paths classified by ESC type — ESC1 through ESC9.
azure
Azure / Entra ID attack paths across 38 cloud relationship types.
paths
Top-K ranked attack paths between any two nodes. Scored, noise-rated, with per-hop abuse tips.
simulate
Step-by-step narrative on the best path. Flags high-noise steps with suggested alternatives.
owned
Tier-0 reachability from a single owned node with full hop chains.
blast
Total blast radius from an owned node — reachable nodes, exec hosts, credential sources.
chokepoints
Betweenness centrality ranking. Find the one account whose hardening removes the most paths. Requires networkx.
matrix
Reachability matrix — every user vs every T0 node with hop count.
htmlreport
Self-contained interactive HTML report covering all analyses. One file, open in any browser.
Engagement Workflows

From no creds
to Domain Admin

The commands build on each other. Each phase uses the output of the previous one to narrow focus and prioritize effort.

  1. 01
    Orient the attack surface

    Run info first. Verify Tier-0 node count, check all primitive counts at once. This is your engagement briefing.

  2. 02
    Build your target list

    bulk ranks every enabled user by hop count to T0. kerberoast shows which of those are worth cracking. Combine both.

  3. 03
    Assess a compromised account

    owned tells you whether the account leads anywhere. blast tells you how much. No T0 reachability means move on.

  4. 04
    Plan the path

    paths gives ranked alternatives with per-hop abuse tips. simulate renders the best path step-by-step, high-noise steps flagged.

  5. 05
    Generate deliverables

    htmlreport for the client. report --format json for automated tooling. blast --format json for the impact slide.

Operational Security

Route around
what's off-limits.

OPSEC flags filter the graph at the edge level. Any path requiring a blocked technique simply won't be returned — the router finds alternatives instead.

FlagWhat it blocksUse when
--stealthAll edges with detection risk ≥ 7 (LSASS, DCSync, DCOM, AZ Global Admin)MDI deployed, monitored environment
--no-lsassHasSession edgesEDR blocks LSASS (CrowdStrike, SentinelOne)
--no-dcsyncDCSync, GetChanges, GetChangesAllROE prohibits replication attacks
--no-rdpCanRDP edgesInteractive sessions out of scope
--no-aclAll 13 ACL relationship typesACL abuse restricted by ROE
--no-execAdminTo, CanRDP, CanPSRemote, ExecuteDCOM, SQLAdminCode execution out of scope
--no-delegationAllowedToDelegate, AllowedToAct, WriteAccountRestrictionsDelegation attacks restricted
--no-adcsAll 9 certificate relationshipsPKI infrastructure out of scope

Flags stack freely. Here's the same path search under strict rules of engagement — whippet finds a quieter route that avoids everything blocked:

bash — constrained pathfinding

IT Admins [MemberOf] → Domain Admins Inherit all group privileges. ⚠ No high-noise steps in this path — clean route.
